# Create a Neural Network from Scratch

This repository contains a Jupyter Notebook that demonstrates how to build, train, and evaluate a simple feedforward neural network from scratch using only NumPy — no deep learning libraries like TensorFlow or PyTorch are used.

## Overview

The notebook walks through:

- Implementing the foundational components of a neural network:
  - Forward propagation
  - Loss computation
  - Backpropagation
  - Weight updates via gradient descent
- Training the network on a sample dataset
- Evaluating the model's performance

This is an educational project aimed at understanding the core concepts behind neural networks by building one manually.
